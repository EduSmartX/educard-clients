ERROR HANDLING GUIDE (for future reference)
-------------------------------------------
The shared package provides these error utilities:

  parseError(err)          → Full NormalizedError object with fieldErrors, nonFieldErrors, etc.
  getErrorMessage(err)     → Single string for toast/alert messages
  extractApiError(err)     → Quick one-liner for Alert.alert() — checks errors, detail, message
  getFieldErrors(err)      → Record<string, string> for setting form field errors
  parseApiErrors(data)     → From form-helpers, maps nested backend errors to flat field errors
                             (used in create/edit screens that need to set per-field errors)
  isDeletedDuplicateError(err) → Check if a duplicate-deleted record exists
  getDeletedDuplicateMessage(err) → User-friendly message for duplicate-deleted
  getDeletedRecordId(err)  → Extract the deleted record's public_id

When to use what:
  - Alert.alert('Error', extractApiError(err))        → Simple error alerts
  - const { fieldErrors } = parseApiErrors(data)      → Form screens with per-field validation
  - toast.error(getErrorMessage(err))                  → Web toast messages
  - applyFieldErrors(err, setError)                    → Web react-hook-form integration
